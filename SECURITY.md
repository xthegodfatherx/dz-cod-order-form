# Security policy

Please **do not** open a public issue for security problems.

Report them privately through [GitHub security advisories](https://github.com/xthegodfatherx/dz-cod-order-form/security/advisories/new). Include the plugin version, what an attacker can do, and the steps to reproduce. You will get an answer within a few days, and credit in the changelog if you wish.

Supported versions: the latest release.
